Importar Transações de Arquivo CSV

Selecione um arquivo CSV para importar suas transações. O arquivo deve conter as seguintes colunas, nesta ordem:

Data, Descrição, Valor

Formato da Data: Use o formato AAAA-MM-DD (ex: 2025-11-11).
Formato do Valor: Use ponto (.) como separador decimal (ex: 150.75 para R$ 150,75). Para despesas, use um sinal de menos (-) na frente do valor (ex: -150.75).
